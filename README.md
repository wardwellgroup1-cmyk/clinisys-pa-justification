# CliniSys Prior Auth Justification

Generate payer-ready medical necessity documentation in under 3 minutes.

## Features

- **6-step wizard interface** - Guides clinicians through comprehensive PA documentation
- **Multi-format output** - Letter, chart note, and appeal draft generation
- **Payer intelligence** - Adapts to specific payer requirements and denial patterns
- **Real-time scoring** - Displays internal approval likelihood score with improvement suggestions
- **Local processing** - No data leaves your device; fully HIPAA-compatible

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
git clone https://github.com/wardwellgroup1-cmyk/clinisys-pa-justification.git
cd clinisys-pa-justification
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```

## Deployment to Vercel

```bash
vercel
```

Or connect your GitHub repo to Vercel for automatic deployments on push.
